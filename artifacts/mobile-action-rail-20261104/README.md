# Mobile action rail

Localhost Playwright evidence (`tests/browser/mobile-action-rail.mjs`) for the phone
action rail at 390px and 430px, light and dark themes.

The rail starts with the navigation toggle and Home, then continues directly with
Search. The workbench launcher and the `.dashboard-rail-top` divider are absent;
the Home-to-Search gap matches the regular 2px icon gap.

Verified without console or page errors.
