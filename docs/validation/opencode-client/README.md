# OpenCode server client validation

[Before](before.png) · [After](after.png)

Real localhost browser captures with a disposable mock host shell and real
server-side provider adapters. The before capture uses the previous release's
adapter; the after capture uses this change. Host projects and sessions are
synthetic. Neither provider response is mocked.

The old default urllib User-Agent produces Cloudflare HTTP 403 while Gemini
remains available. The explicit Workbench User-Agent produces OpenCode remaining
allowances of 100% rolling, 100% weekly, and 99% monthly. Gemini remains at 100%
five-hour and 85% weekly. Refresh succeeds. Desktop (1440×1000) and mobile
(390×844), light and dark, were checked locally. Browser requests, responses,
DOM, console and Web Storage were checked against the server credential, with
no matches and no external browser requests. This is localhost validation,
not validation of the installed daily instance.
